## 1. Калькулятор НДФЛ / зарплата на руки -`/ndfl`

**Приоритет: 1 (открывает прод, Этап 3)**

| Тип            | Запросы                                                                                       |
| -------------- | --------------------------------------------------------------------------------------------- |
| Главный        | калькулятор ндфл, калькулятор зарплаты на руки                                                |
| Околоцелевые   | ндфл с зарплаты калькулятор, калькулятор ндфл онлайн 2026, зарплата на руки после вычета ндфл |
| Информационные | что такое ндфл простыми словами, как считается прогрессивная шкала ндфл, ставки ндфл 2026     |

**Сезонность:** стабильный спрос круглый год (самая частая финансовая проверка «сколько получу на руки»).

**Конкуренты в топе:** `ppt.ru/calc/ndfl` -сильный лидер: ~2500+ слов текста, 2 таблицы с реальными цифрами, FAQ на 7 вопросов, скриншоты примеров, 10 внутренних ссылок на смежные калькуляторы. `calc.consultant.ru/ndfl`, `nalog-nalog.ru`, `glavkniga.ru/calculators/ndfl_2025` -заметно слабее (у glavkniga ~400-500 слов, нет FAQ, нет таблиц с примерами).

**Вывод:** высокая планка задал ppt.ru -чтобы конкурировать, нужен объём текста и FAQ не хуже (это уже заложено в шаблон Этапа 1), но glavkniga и nalog-nalog показывают, что с середняками можно и нужно соперничать за счёт более полного контента.

## 8. ~~Калькулятор ОСАГО~~ → Калькулятор детских вычетов по НДФЛ -`/detskie-vychety`

**Приоритет: 8 -решение принято, заменено**

Поиск по конкурентам подтвердил опасение, уже заложенное в план: в топе выдачи по запросу «калькулятор осаго» находятся не справочные калькуляторы по формуле, а **страховые агрегаторы и сами страховые компании** (polis.online, drom.ru, rgs.ru/Росгосстрах, ingos.ru/Ингосстрах, brobank.ru, eosago.online) -они дают точную цену по гос. номеру/данным водителя через API страховых, а не приблизительный расчёт по формуле коэффициентов. Наш калькулятор «ориентировочный расчёт» был бы структурно слабее их UX (они дают точную цену за 2 клика), и конкурировать за топ-10 с реальными страховщиками в YMYL-тематике намного тяжелее, чем в остальных нишах плана.

**Решение (перед стартом Этапа 10):** заменили на «калькулятор детских вычетов по НДФЛ» -прямое продолжение темы НДФЛ, та же аудитория, конкуренты слабее (в основном бухгалтерские порталы, а не агрегаторы с API).

| Тип            | Запросы                                                             |
| -------------- | ------------------------------------------------------------------- |
| Главный        | налоговый вычет на детей, калькулятор детских вычетов по ндфл       |
| Околоцелевые   | налоговый вычет на детей 2026, стандартный вычет на ребенка сумма   |
| Информационные | сколько составляет вычет на детей, до какого дохода действует вычет |

**Конкуренты в топе:** glavkniga.ru, nalog-nalog.ru, 26-2.ru, rnk.ru, taxcom.ru, zarplata-online.ru -преимущественно бухгалтерские информационные порталы, у большинства нет интерактивного калькулятора именно с расчётом реальной экономии по НДФЛ (не просто справочная таблица сумм) -это и есть наше отличие.

## Что расширять первым (решение 24.08.2026)

Не плодить страницы вслепую: 8 URL уже есть, тонкий сайт в YMYL хуже, чем 8 сильных. Следующие URL — по убыванию отдачи на осень 2026.

1. **`/bolnichnyy-po-uhodu`** — тот же СДЗ/МРОТ/базы СФР, сезон гриппа, кластер больничного самый широкий из зарплатных. **Опубликован 26.08.2026** (Часть 2, Этап 16 плана) — приоритет 9 в `registry.ts`.
2. **`/zarplata-na-ruki`** — только если после снятия Wordstat точная частота «зарплата на руки» не каннибалит `/ndfl`. Пока на `/ndfl` уже есть этот интент.
3. **`/vykhodnoe-posobie`** — рядом с компенсацией отпуска, увольнения круглый год. **Опубликован 26.08.2026** (Часть 2, Этап 16 плана) — приоритет 10 в `registry.ts`.
4. **Не дробить `/peni`** на две страницы, пока не будут точные частоты «пени ЖКХ» vs «пени налоги»: шумный кластер, одна страница с переключателем уже закрывает оба интента.
5. **Не плодить URL под детские вычеты.** Усилить `/detskie-vychety` под запрос «налоговый вычет на детей» (главный ключ в registry уже сменён). Кластер «калькулятор детских вычетов» почти пустой.
6. **Отпускные** не расширять новыми URL до весны 2027: пик сезона прошёл, страница уже есть.

Домен: **`easycalc.ru` занят** (живой сайт с математическими калькуляторами). РСЯ, Вебмастер и Метрика — только на своём свободном домене 2-го уровня. Кандидаты к проверке в регистраторе: `zhizncalc.ru`, `easykalk.ru`, `calcprosto.ru`.
